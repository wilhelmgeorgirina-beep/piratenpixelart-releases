# Piratenpixelart - Downloads

Hier liegen die fertigen Windows-Versionen von Piratenpixelart zum Herunterladen (unter "Releases").

1. Das neueste Release oeffnen und `piratenpixelart-windows.zip` laden.
2. Das Zip in einen eigenen Ordner entpacken (nicht nach "Programme", das Spiel muss sich dort selbst aktualisieren duerfen).
3. `Piratenpixelart.exe` starten. Das Spiel aktualisiert sich danach von selbst.
